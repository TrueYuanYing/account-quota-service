# 普通用户：账号、个人API与内置额度

本教程对应产品V0.3.11/build94，按钮以已核实源码为准；本机源码示例不会替你创建真实账号或购买额度。

## 注册、登录与找回

进入账号页，可使用密码登录，或切到验证码登录/注册。输入本人可收信邮箱，发码后在有效期内填写验证码。邮箱验证后可设置10–128位、包含字母与数字的密码，也可稍后补设。验证码登录与密码登录都可进入“忘记密码”，通过现有邮箱验证后重设新密码。

部分旧账号没有明确设密标记，首次会提示补设；这个提示不代表能读取旧密码，密码是单向哈希。管理员也不能解密或展示原密码。收不到邮件先检查垃圾箱、邮箱拼写与冷却时间，再用反馈入口说明时间和邮箱，不把验证码贴到公开issue。

会话由GoTrue SDK续期，凭据存Android Keystore独立空间；退出会清会话并写退出标记。断网不阻已有本机听写/笔记。账号登录目前不等于云备份：资料仍属于当前安装，切账号没有实现完整资料分区或云同步。重要内容自行导出备份。

## 使用个人API

进入“设置 → AI连接与模式”，启用“使用自己的API”，选择供应商、模型、Base URL/协议，输入本人API Key并保存。普通保存不发送模型请求；显式连接测试和真实答题会按供应商规则收费。Key不要放截图或分享给别人，换设备按自己的安全策略重新配置。

Base URL需HTTPS，可填兼容Chat Completions或Anthropic Messages；不能在URL查询参数里塞Key。模型ID必须是本人账号可用的准确名称。401/403核对Key与权限，404核对URL/模型，429核对限流/额度，超时可取消后再发。不要把更换供应商说成已验证更便宜或更准确。

个人API答题不扣IKO内置额度；当前产品翻译、云端纠错、摘要仍有账号权益门槛，不能理解为填Key就无条件开放全部功能。本机ASR、截图OCR与本地笔记不按模型API计次。

## 内置额度充值

进入“设置 → 账户额度 → 额度与充值”，先核对登录账号、剩余四类额度与最近订单。当前服务端商品为账户累计额度，无日历到期，同档/跨档重复购买都叠加：

| 价格（元） | 答题（次） | 云端纠错（次） | 翻译（次） | 课堂摘要（次） |
| --- | ---: | ---: | ---: | ---: |
| 5.99 | 150 | 400 | 150 | 25 |
| 9.99 | 400 | 1000 | 400 | 60 |
| 29.99 | 2000 | 5000 | 2000 | 300 |

购买先选择服务端商品并创建订单，再核对金额、数量和计量说明。可在App内H5支付、唤起支付宝或用同一订单二维码。订单创建时的账号是到账归属，不靠支付页自行修改。通常未付15分钟过期；遇网络中断先查原订单，避免重复付款。

付款后返回App刷新额度和订单。支付宝返回页/截图不是入账依据；只有服务端验签、金额/商户/状态核对及查单后才入账。未到账时从最近订单提交“订单反馈”，带订单号和发生时间，切勿贴账号token、验证码或支付密钥。管理员撤销权益不等于已完成支付宝资金退款。

## 怎样计次

请求发送到云模型后计1次，包括超时、中断或没有有效答案；成功数量是另外的统计。登录、额度、繁忙、配置或输入校验等明确未派发的前置拒绝不扣。手动重新生成是新请求，长摘要的分段与合并各自计次。请先读确认页计量说明再付款。

普通账号充值与管理版的管理员激活制度分开；不要下载或分享管理APK。
